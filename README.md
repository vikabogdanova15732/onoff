# ON/OFF монитор

Сервер, который показывает состояние ON или OFF на весь экран. Состояние синхронизируется между всеми устройствами в одной сети.

## Установка и запуск

### 1. Скачайте файлы

Создайте папку и поместите в неё два файла:
- `server.py` — сам сервер
- `index.html` — страница с состоянием

### 2. Запустите сервер

Откройте терминал (командную строку) в этой папке и выполните:

python server.py


### 3. Откройте в браузере

**На компьютере:**

http://localhost:8000


**На телефоне (в той же Wi-Fi сети):**
- IP-адрес покажет сервер при запуске (например `http://192.168.1.100:8000`)
- Введите этот адрес в браузере телефона

## Как пользоваться

| Адрес | Что увидите |
|-------|-------------|
| `http://localhost:8000` | OFF (красный фон) |
| `http://localhost:8000/on` | ON (зелёный фон) |
| `http://localhost:8000/off` | OFF (красный фон) |

## Синхронизация между устройствами

1. Откройте сайт на компьютере и телефоне
2. На телефоне перейдите по адресу `http://IP:8000/on`
3. На компьютере состояние автоматически изменится на ON
4. То же самое работает в обратную сторону

## Как остановить сервер

В терминале, где запущен сервер, нажмите `Ctrl + C`

- Python 3.6 или новее
