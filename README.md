# ON/OFF Web Server

Простой локальный HTTP-сервер на Python, который показывает текущее
состояние: **ON** или **OFF**.

Состояние переключается через URL-адреса:

-   `/on` --- включить состояние **ON**
-   `/off` --- выключить состояние **OFF**

После переключения страница меняет цвет фона:

-   🟢 зелёный --- **ON**
-   🔴 красный --- **OFF**

## Требования

-   Python 3.x
-   Дополнительные библиотеки не нужны --- используются только
    стандартные модули Python.

## Запуск

``` bash
python server.py
```

После запуска в терминале появятся адреса:

-   На компьютере: `http://localhost:8000`
-   На телефоне: `http://<локальный-ip>:8000`

## Использование

### Открыть страницу на компьютере

``` text
http://localhost:8000
```

### Включить

``` text
http://localhost:8000/on
```

### Выключить

``` text
http://localhost:8000/off
```

Если телефон находится в той же Wi‑Fi сети, можно открыть сервер с
телефона:

``` text
http://<локальный-ip>:8000
```

Например:

``` text
http://192.168.1.10:8000
```

## Как это работает

Сервер запускается на порту **8000** и принимает HTTP-запросы.

-   При переходе на `/on` глобальное состояние меняется на `on`.
-   При переходе на `/off` глобальное состояние меняется на `off`.
-   Главная страница всегда показывает текущее состояние крупным текстом
    по центру экрана.

## Остановка сервера

Чтобы остановить сервер, нажмите в терминале:

``` text
Ctrl + C
```
